# Tests

Интеграционные тесты для проверки оплаты и exactly-once выдачи товара.

## Запуск

Сначала запустить сервисы проекта:

```bash
docker compose --env-file .env.docker up --build 
```

После запуска контейнеров выполнить тесты:

```bash
pytest -v
```

## Покрытие

`test_parallel_payment_webhooks_create_one_delivery`
Проверяет обработку параллельных webhook-запросов для одного заказа. При одновременной оплате создаётся ровно одна доставка и выдаётся один товар.

`test_duplicate_payment_webhooks_are_idempotent`
Проверяет идемпотентность повторных webhook-запросов с одним `event_id`. Повторная обработка не создаёт дополнительную доставку или повторную выдачу товара.

Тесты используют уникальные идентификаторы заказов и автоматически удаляют созданные тестовые данные после выполнения.
